# Installing / Cài đặt

## English

### The easy way (once it's on the Chrome Web Store)

1. Open the link your colleague shared.
2. Click **Add to Chrome**, then **Add extension**.
3. Click the puzzle-piece icon (top-right of Chrome) and pin **Attendance
   Tracker for Zoho People**.
4. Sign in at [people.zoho.com](https://people.zoho.com/) once. Done — the
   icon shows a countdown, and updates install themselves.

### The manual way (until then)

1. Download the extension zip (ask whoever shared this) and double-click it —
   you get a folder. Put that folder somewhere permanent (e.g. Documents), not
   Downloads: if the folder is deleted, the extension dies.
2. In Chrome, copy-paste `chrome://extensions` into the address bar.
3. Turn on the **Developer mode** switch (top-right corner).
4. Click **Load unpacked** (top-left) and pick the folder from step 1.
5. Pin the icon via the puzzle piece, sign in at people.zoho.com once.

Updating manually: replace the folder's contents with the new version's files,
then click the circular-arrow **Reload** on the extension card.

## Tiếng Việt

### Cách dễ (khi đã có trên Chrome Web Store)

1. Mở link được chia sẻ.
2. Bấm **Thêm vào Chrome**, rồi **Thêm tiện ích**.
3. Bấm biểu tượng mảnh ghép (góc trên phải Chrome) và ghim **Attendance
   Tracker for Zoho People**.
4. Đăng nhập [people.zoho.com](https://people.zoho.com/) một lần. Xong — icon
   hiện đồng hồ đếm ngược, cập nhật tự động.

### Cách thủ công (trong lúc chờ)

1. Tải file zip (hỏi người chia sẻ), nhấp đúp để giải nén ra một thư mục. Để
   thư mục ở chỗ cố định (ví dụ Documents), đừng để trong Downloads — xoá thư
   mục là tiện ích chết.
2. Trong Chrome, dán `chrome://extensions` vào thanh địa chỉ.
3. Bật công tắc **Developer mode / Chế độ nhà phát triển** (góc trên phải).
4. Bấm **Load unpacked / Tải tiện ích đã giải nén** và chọn thư mục ở bước 1.
5. Ghim icon qua biểu tượng mảnh ghép, đăng nhập people.zoho.com một lần.

Cập nhật thủ công: thay nội dung thư mục bằng bản mới, rồi bấm nút **Reload**
(mũi tên tròn) trên thẻ tiện ích.

## For IT admins (optional, best of all)

If the team is on managed Chrome, IT can force-install for everyone via the
`ExtensionInstallForcelist` policy pointing at the Web Store id — zero user
action, zero developer mode, centrally updated.
